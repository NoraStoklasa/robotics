# Contributing

## Branches

Name branches `stream/short-slug`, e.g. `vision/isolate-poster-region`, `navigation/astar`,
`integration/mission-state-machine`.

## Pull requests

- One pull request per issue.
- Reference the issue number in the PR description.
- **Every pull request needs a review from an owner of a different stream.** The rubric examines
  each member's understanding of the whole system, not just their own area — cross-stream review
  is how we keep everyone able to answer questions about the parts they didn't write.

## Logging

- After any code, docs or config change, add one row to `docs/contribution_log.md`
  (date, member, issue, what you did).
- Engineering decisions with a criterion and measured evidence go in `docs/decision_log.md`.
- Failed test runs go in `docs/failure_log.md`, logged the same day they happen.

See `AGENTS.md` for the repo-wide rules AI assistants follow when editing this project.
