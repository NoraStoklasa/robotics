# Failure Log

Per issue [27](.github/issues/27-decision-and-failure-logs.md). Every test run that fails, including during development,
gets a row the same day it happens — failures are engineering evidence for the report, not something to hide.

Target: at least six rows by the end of M4, spanning both vision and navigation. Issue [21](.github/issues/21-failure-cases-and-fixes.md)
turns this into the report's failure-cases chapter, so name *where the first incorrect decision occurred* once known.
